# Floating AI Overlay (Android)

تطبيق أندرويد يعرض نافذة ذكاء اصطناعي عائمة فوق الشاشة مع إمكانية السحب وإرسال الأسئلة واستقبال الردود، ومزود بسير عمل GitHub Actions لبناء ملف `app-debug.apk` تلقائياً.

## طريقة الاستخدام
1. ارفع محتويات هذا المجلد إلى مستودع جديد على GitHub (فرع `main`).
2. انتقل إلى تبويب **Actions** وانتظر انتهاء بناء الـ APK، ثم نزّل ملف `app-debug.apk` من **Artifacts**.
3. ثبّت التطبيق على هاتف أندرويد، وأدخل مفتاح API الخاص بك، ثم فعّل صلاحية **الظهور فوق التطبيقات الأخرى (Display over other apps)**.
